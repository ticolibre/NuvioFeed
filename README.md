# TicoLibre Catalogues

A curated catalog addon for **Nuvio** and **Stremio**. It serves movie and series catalogs with metadata powered by [TMDB](https://www.themoviedb.org/).

## Install

```
https://raw.githubusercontent.com/ticolibre/NuvioFeed/main/manifest.json
```
